### 📦 URL Shortener Service
## 📄 Описание
### URL Shortener Service — микросервис, отвечающий за сокращение ссылок. Он включает в себя:

Генерацию коротких кодов для длинных URL (Base62, защита от коллизий).
Редирект по короткой ссылке на оригинальный адрес.
Учёт статистики переходов (количество кликов по ссылке).
Этот сервис обеспечивает быструю обработку запросов за счёт кэширования в Redis.

### ⚙️ Технологии
## Основные технологии
- Java 17: современный язык программирования для создания надежных приложений.
- Spring Boot 3.x: фреймворк для упрощения разработки приложений на Java.
## Базы данных
- PostgreSQL: реляционная база данных для хранения ссылок и статистики.
- Redis: база данных в памяти для кэширования популярных ссылок и ускорения редиректов.
- Liquibase: инструмент для управления версиями базы данных.
## Взаимодействие между микросервисами
- OpenFeign: клиент для взаимодействия с RESTful API других микросервисов.
## Тестирование
- JUnit 5: фреймворк для написания модульных тестов.
- Mockito: библиотека для создания моков и шпионов в тестах.
- Testcontainers: библиотека для тестирования с использованием контейнеров Docker.
## Дополнительные инструменты
- Lombok: библиотека для упрощения написания Java-кода.
- MapStruct: инструмент для автоматического маппинга между объектами.
- Springdoc OpenAPI: для генерации документации API.
- Docker: контейнеризация приложения.
- Slf4j: абстракция для логирования.

## 🔗 Связанные сервисы
- Analytics Service: для передачи данных о переходах по ссылкам.
- Notification Service: для уведомлений (если ссылка используется в рассылках).
